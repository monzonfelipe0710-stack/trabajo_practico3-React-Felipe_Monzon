# Nexo Play

Nexo Play es una pequeña tienda y biblioteca de juegos para descubrir títulos, guardar favoritos y armar una colección personal.

## Funciones

- Explorar un catálogo de juegos ficticios por género.
- Consultar la información y el precio de cada título.
- Añadir juegos a la biblioteca.
- Guardar y quitar juegos de la lista de deseos.

La colección es local y se reinicia al cerrar la app; no se necesita una cuenta ni se solicitan permisos del dispositivo.

## Iniciar el proyecto

Requisitos: Node.js y npm.

```bash
npm install
npx expo start
```

Para abrir la versión web:

```bash
npm run web
```
